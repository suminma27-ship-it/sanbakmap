# 전국 정밀 원본 접점 감사 v128

사용자가 제공한 `닭.zip` 원본 EPSG:5179 SHP 16개를 대상으로 2,902개 산의 선형 간 거리를 직접 검사했다.

* 입력 원본 SHA-256: `7426dbf4bbf07ad31524a16eabe9dfad8f358a75ac519dcf3f09c4ebc178b76a` (v102 manifest와 동일)
* 원본 59,397 피처, 66,503 선형 부분
* 35m 이내 선형 쌍 `144,990`개 (3m 단순화 자료 v125보다 582개 많음)
* `tools/audit-original-35m-v128.py`로 재실행 가능: Python `pyshp`와 `shapely>=2` 필요
* 출력은 산별 gzip JSON. 각 쌍에 두 원본 SHP의 파일 이름, 원본 행, 파트 번호, 정확한 최근접 EPSG:5179 좌표, 선형 시작점으로부터의 길이(m), 2D 기하 유형을 보존한다.
* 총 2,345개 산의 산별 상세 후보는 이번 대화에서 ZIP으로 제공했다. 대용량 SHP 원본은 저장소에 중복 업로드하지 않았다.

### 한계령 기준 사례

v69 원본에는 사용자가 연결을 요청한 한계령의 특정 두 지점을 73.19m 임시 연결선으로 잇는 코드가 있다. 전국 산림청 원본 SHP `51.zip` 2075번 피처와 2086번 피처 사이 최근접 간격은 48.7268m다. 즉 35m 제한만 적용하면 이 사용자가 확인한 연결을 복원하지 못한다.

### 주의

정밀한 수평 좌표의 일치 또는 가까운 거리만으로 실제 통과할 수 있음을 증명하지 않는다. 교량, 절벽, 입체 교차, 2016년 이후 통제 등을 이 데이터로 알 수 없다. 후보는 **계획용이며 통행 확인되지 않았다.** 기존 사이트의 등산로 경로나 고도자료는 변경하지 않았다.

```bash
python -m pip install pyshp 'shapely>=2'
python tools/audit-original-35m-v128.py '/path/to/닭.zip' --outdir ./original-contacts-v128
```
