# v135 — 337개 우선 접합 고도 정밀 교차검증

## 작업 목적

기존 90m 간격 DEM 표본이 35m 이내 데이터 접합의 국소적인 고도 변화와 충돌하는 문제를 **전국 공통 원본 데이터 대조**로 검사했다. 경유지 UI·지도의 기능·공개 경로망은 추가하거나 수정하지 않았다.

## 원본 자료와 방법

- 사용자가 업로드한 16개 산림청 원본 SHP의 SHA-256 **7426dbf4bbf07ad31524a16eabe9dfad8f358a75ac519dcf3f09c4ebc178b76a**.
- v129 계획용 그래프, v131 337개 고도 검사, v134 복원 표본 및 고도 포함 `output_elevation.zip`에서 **609개 원본 간선**을 찾아 원본의 EPSG:5179 중간 좌표 전체와 대조했다.
- 유효한 원본-3D 선형 대응은 원본 구간의 전체 거리·정밀한 중간 좌표 일치(0.3m 이하), 시작·종점 일치, 중복 고도 불일치 배제 후 채택했다. **시작·종점이 같은 순환형 등산로는 전체 버텍스 순서**로 비교했다.
- 각 계획용 접합 양쪽의 원본 간선상 위치를 따라 직접 3D 고도값을 읽고, v131/v134의 90m 간격 표본 보간 고도차와 비교했다.
- 2016년 중심의 과거 자료임. 3D 고도 포함 GeoJSON은 실제 DEM 래스터 해상도, 수직기준, 현재 통행 가능 여부를 인증하지 않는다.

### 가장 큰 재분류 사례

| 산코드 / 연결 ID | 90m 표본 고도차 | 3D 직접 고도차 |

분류 변경 19개 중에는 5m 경계값을 **0.003m** 차이로 넘어선 사례도 포함되어 있다. 따라서 판정 변경 건수는 현장 위험 건수가 아니며, 90m 고도 표본화로 인한 **자료 분류 민감도**를 뜻한다.

**고도 데이터가 완전해져도 실제 등산로 연결을 증명하지는 않는다.** 원본 SHP와 3D 고도자료는 실측 접근/탐방 허가·교량·절벽 및 35m 틈의 실제 지형을 입증하지 못한다. 물리적 연결 확인 0건, 승인된 신규 등산로 0건.
