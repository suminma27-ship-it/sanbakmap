- 원본 구간 표시/숨김, GPS 연결 후보/미검증 접점 강조, 모바일 지도 이동 및 확대, 근접 접점 확대/정상 기준점, 출처별 GeoJSON 추출 지원. `verified:false`, `allow_in_routing:false`를 유지하여 실제 전국·국립공원 루트 엔진에는 편입하지 않음.

## v64 업데이트 (2026-11-07)
- 사용자 요청에 따라 **전국 원본 GeoJSON의 30m 이내 다른 연결 요소 간 가까운 선 끝 후보를 전체 연결선으로 추가**. 자체 감사에서 74개 산코드, 201쌍 확인. 기존 v63의 후보 상위 8쌍 제한을 제거하고 원본 ZIP을 선택했을 때 모든 후보를 지도에 계획용 연결로 표시.
- 201개 계획용 연결은 **원본에 없던 좌표 간 직선**이며, 실제 길·통행 가능 구간으로 인증하지 않는다. 원본의 선형과 다운로드는 유지. 진단 패널에서 별도 `계획용 연결 GeoJSON 저장`을 눌러 출처·거리·verified:false 태그를 포함한 버전을 내보낼 수 있다.
- 전국 ZIP 없는 압축 SVG **미리보기**는 좌표 역변환이 가능하지 않아 원래 소스 미리보기 그대로 표시. 계획용 연결선은 상세 ZIP 열기 이후에만 보인다. 전국 구간 탐색·고도는 여전히 구현 전.
- 이전 설악산 **한계령 부근 스크린샷**에서 가까이 지나지만 바로 이어져 보이지 않던 기존 네트워크의 선형 2개(기존 edge 9·22) 사이의 근접 좌표에 약 73m 가상의 직접 연결을 추가. 두 소스 edge는 삭제/재번호 지정하지 않고 복제 분할 간선과 계획용 접속 간선을 추가하므로 기존 보관된 edge ID를 유지한다.
- 설악산 계획용 접속 간선은 편집기의 연결망 길찾기에 참여하며, 실제 통행로 검증이 되지 않았으므로 이를 포함한 경로에서는 미검증 안내를 표시·요약 복사에 추가한다. 가까운 직선 표시가 실제 통행 가능을 보장하지 않음.
- 국립공원 다른 지역의 네트워크 데이터와 코스, PWA UI, 경유지 편집 기록은 유지. 실제 모바일·현장 검증 필요.

## v62 업데이트 (2026-11-07)
- 전국 지도에서 **상세 원본 ZIP**을 선택했을 때 해당 산코드 GeoJSON의 공유 정점을 기준으로 연결 요소 수, 선 끝 개수, 서로 다른 연결 요소에 속한 30m 이내의 가까운 선 끝 후보를 계산하는 접이식 '원본 좌표 연결 진단' 추가.

- 연결 진단은 **자료의 위상 진단**이지 산행 가능한 등산로 검증이 아니며, 현장 통제 여부는 반영하지 않음.
