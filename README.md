**전국 코스 계획 실험: v118** — 원본 GIS와 정밀 일치하는 지도 위 연결 노드를 직접 선택할 수 있음. **기존 국립공원 화면은 v98, 설악산 원본 선형은 v92 계열** (현행 탐방 허가 미검증).

웹사이트: https://suminma27-ship-it.github.io/sanbakmap/

## v118 설악산 계획용 근접 접합(최대 5m) · 추정 구간 별도 시각화 (2026-11-08)
- 기존 정밀 GIS 기하 일치 조건은 과거 좌표의 소수점 오차와 끝점–다른 선분의 근접을 모두 단절로 처리했다. 이를 해결하기 위해 **원본 정밀 접점 모드**를 보존하고, 기본 **계획용 근접접합 5m 모드**를 추가했다.
- `core/nationwide-knps-nearby-v118.js`는 2018 설악산 공단의 원본 탐방로 끝점이 서로 다른 구성요소의 원본 선분 내부에 최대 5m 이내로 근접한 **7개 검토용 접합**을 계산한다. 이 결과 원본 정밀 16개 연결요소에서 계획용 9개 연결요소가 된다. **기존 원본 22개 간선 ID 및 고도자료는 불변**이며 다른 산 연결망을 자동 합치지 않는다.
- 지도에서 **주황 점선**은 실제 통행·개방·고도 미확인인 근접접합을 뜻한다. 파란 선은 기관 수록 원본 경로를 바탕으로 그린 계획 경로다. 선택 경로에 근접접합이 있으면 연결 수·총 틈 거리 및 위험 안내를 표시하고, **새로 분할한 부분에 실제 DEM 표본이 없는 경우 고도그래프를 만들지 않는다.**
- 원본 연결망만 보려면 `원본 정밀 접점만`을 선택해 즉시 비교할 수 있다. 5m 밖의 누락, 복수의 겹치는 후보, 고도차·교량·폐쇄 여부는 여전히 미확인이며, 산행 안내나 공식 통행 허가의 근거가 아니다. 전국 산림청 연결망은 이번 단계에서 자동 근접병합하지 않았다.
- `tests/nationwide-knps-nearby-v118.mjs`와 `tests/nationwide-nearby-browser-v118.mjs`에서 원본 그래프 보존, 5m 원본선 접합, 주황색 경로, DEM 차단, 원본 모드 복귀를 검사한다.

## v106 바탕지도 없이 전국 등산로·선택 코스 표시 (2026-11-08)
- `nationwide-plan.html`에 SVG 기반 **기관 수록 등산로와 계산된 코스** 레이어를 추가. 배경 지도 타일/OSM 없이 지도 줌·이동·전체 보기를 지원하며, 기하학적 코스 계산과 현재 입산 허가는 별개.
- 산림청 원본 노드는 **EPSG:5179 데시미터 정수**, KNPS 원본 좌표는 **WGS84**. `core/nationwide-map-v106.js`는 EPSG:5179 TM 투영으로 공통 화면 좌표를 구성하고, 산림청 기관 수록 등산로는 기존 3m 단순화 버킷에서 산코드별로만 불러온다. KNPS는 2018 시설 원본 GeoJSON의 탐방로 선형만 렌더링.
- **경로 강조의 무결성**: 코스 엔진의 원본 edgeIds를 원본 소스 파일명/행/부분 index 또는 KNPS 원본 feature ID로 대조하고, 각 끝점을 선형에 투영하여 해당 부분만 잘라 보여 준다. 3m 단순화 선형이 원본과 정합되지 않거나 구간 표시 길이 검증에 실패하면 그 부분은 **생략하고 누락 구간 수를 알림**. 두 노드를 직선으로 임의 연결하지 않음. 원본 경로 계산 거리는 3m 화면 단순화 선형에서 계산하지 않는다.
- 15cm 이내로 원본 노드에 연결된 기관 주요지점은 참고 마커를 보여주며, 클릭으로 계획 경유지에 추가할 수 있다. 선택 순서 변경/삭제 또는 계산 실패 시 이전 코스 강조는 즉시 제거. 설악산 KNPS/산림청 모드는 다른 원본을 섞지 않고 전환 시 초기화한다.
- `core/nationwide-map-view-v106.js`는 바탕지도와 무관한 SVG 화면만 담당. 기존 DEM은 이 버전에 연결하지 않았으므로 **고도그래프·누적 상승고도는 아직 나타나지 않는다**. 이 선형들은 2016~2018년 역사 자료이며 산행 안내·현행 개방 확정 자료로 사용 불가.
- `tests/nationwide-map-v106.mjs`: 투영 좌표 정확도, 설악산 실데이터 경로 표시, 산림청 소스키 매칭/불일치 누락 처리, 전국 UI 연결, GitHub Pages 배포 포함 검증.

## v104 전국 공통 경유지 코스 계산 실험 (2026-11-08)
