# v140 — 전국 원본 정밀좌표와 0.1m 노드 양자화 대조

원본 산림청 SHP(EPSG:5179)의 간선 양쪽 좌표 **134,370개**를 전국 2,902산·공원 원본 v102 그래프의 67,185간선, 59,301노드와 대조했다. 원본 ZIP(v102, v129, v139 포함)의 SHA-256을 검사하고 v129 그래프의 원본 노드·간선 접두부가 v102와 일치함을 확인했다.

## 전국 지표
- 최대 원본 좌표 대 양자화 노드 편차 **0.070569m**.
- 같은 양자화 노드에 서로 다른 원본 좌표가 연결된 경우 **1,722곳**. 이 중 원본 XY 최대차 1mm 초과 **470**, 1cm 초과 **368**, 5cm 초과 **114**, 10cm 초과 **2**. 1,722 전부를 오류로 분류할 수 없으며 상당수는 극히 작은 부동소수점 차이이다.
- 서로 다른 그래프 노드 사이에서 원본 끝점 간 거리가 2cm 이하인 경우 **4쌍**. 그중 원본 연결요소가 서로 분리된 경우 **1쌍**.
- 우선 사례: 산코드 **301101201**, 원본 노드 **81, 80**, 원본 좌표 최근접 **0.011600m(1.16cm)**, 서로 다른 원본 그래프 연결요소. 실제 보행로 연결인지, 0.1m 셀 양자화 때문인지 검증 필요. 임의로 이어 붙이지 않았다.
- 전국 원본 연결요소 산별 합계 **3,571**. 200m 이하 산·공원 포함 전부 보존.

## 재현·원칙
모든 원본 간선의 source_parts 원본 파일/SHP row/part/버텍스 범위를 통해 EPSG:5179 원본 좌표를 읽고 양자화 XY(정수 좌표 ÷ 10)와 비교한다. 한 그래프 노드로 합쳐진 원본 좌표 간 최대거리와, 격자 이웃 셀의 서로 다른 노드가 2cm 이하로 접촉하는지 각각 계산했다. 원본 간선만의 Union-Find로 연결요소를 검사하며 35m 계획 연결은 실제 길로 간주하지 않는다.

대화 산출물 sanbakmap_v140_nationwide_coordinate_precision_audit.zip (SHA-256 a813b28b5f22cb8673348fa42dda1a17ca3548be85b8ac5212a47a3340163b3a)에 2,902곳 코드별 CSV, 동일 노드의 서로 다른 좌표 1,722개별 JSON, 별도 노드 4쌍 JSON 및 audit_v140_precision.py, validate_v140.py, 입력 해시·재현 지침을 제공했다. 독립 재검증: 원본 SHP 상위 12개 노드, 근접 4쌍을 재추출해 일치 확인.

이 감사는 원본 데이터의 정합성 검증만 수행한다. 원본 그래프, DEM, 지도 UI, 실제 경로망, 낮은 산 제외 여부 **변경 없음**. 실통행 가능한 새 연결 **0건**. 2016년 중심의 과거 원본이므로 현장 상태·법적 접근이나 3D DEM 정확도는 별도 확인해야 한다.
