# v138 — 전국 15cm 이하 초미세 원본 간선 정합성 전수검증

## 대상과 방법

v137 미해결 평면 접점의 원인이었던 초미세 원본 그래프 간선을 전국으로 확대했다. 원본 산림청 ZIP SHA-256 `7426dbf4bbf07ad31524a16eabe9dfad8f358a75ac519dcf3f09c4ebc178b76a`, v102 토폴로지 SHA-256 `1b99616f1f40a1b9e5202f05d7de9a001d438b172e66969ab6ebee87f7042183`, v129 그래프 SHA-256 `a672b42904c270c7b8442ae7dd29b64d3efea4ee0a555bd8d60d972222c9b7cb`, v137 진단 ZIP SHA-256 `7e8154b8176a7bff3d29e5abf4ec07ed3fda8f1249e738da6f1d16d93e19e479`으로 검증 입력을 고정했다.

v102의 **2,902개 산·공원, 원본 그래프 간선 67,185개**를 전체 스캔하여 그래프 길이가 0.15m 이하인 521개를 추출했다. 각 간선의 원본 SHP **EPSG:5179 버텍스 범위 전부**를 조회하여 실제 길이와 시작·종료점, 0.1m 단위 그래프 노드 좌표와의 양자화 차이, 출처 ZIP/행/파트/분할 버텍스 인덱스를 대조했다. v129 원본 그래프의 선행 67,185개 간선·59,301개 노드가 원본 v102과 모두 동일한지도 확인했다.

## 정합성 기준 (진단만 적용)

1. 그래프 길이가 15cm 이하면 원본 좌표에서 실제 길이를 재계산한다.
2. 그래프 단위(0.1m 셀) 때문에 동일 노드 또는 길이 0m로 보이는 간선도 **원본 SHP 구간 ID와 원본 좌표·길이를 보존**한다.
3. 같은 원본 파트의 연속 범위가 있어도 버텍스 인덱스 일치, 분기/교차의 전체 보존, 연결요소 불변을 모두 입증하기 전에는 원본 경로를 변경하지 않는다.
4. 고도 미확인 7곳, 기존 35m 접합 후보, 사용자가 별도로 확인한 한계령 예외의 상태를 유지한다. 길이·인접·높이 유사성만으로 새로운 길을 승인하지 않는다.
