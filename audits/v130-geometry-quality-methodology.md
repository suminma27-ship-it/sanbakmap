# 산박지도 v130 · 전국 원본 연결망 자동 품질검사

이번 작업은 **연결 데이터와 검증만 수정**한 단계다. 지도 UI, 경유지 선택, 거리·고도 계산 표시, 배포 경로는 바꾸지 않았다.

## 검사

기존 SHA-256 검증된 산림청 원본에 기반한 v129 계획용 그래프 32개 버킷의 모든 산 2,902개, 35m 이내 접합선 36,084개를 자동 전수 검사했다. 각 연결선에 대해 원본 좌표의 두 앵커 간 거리, 기하학적 유형, 기존 연결망에서의 최단경로 길이(최대 50km), 새로운 연결이 기존과 분리된 구성요소를 연결하는지 여부를 다시 계산했다.

**자동 분류 결과** (합계 36,084개):

| 결과 | 개수 | 후속 취급 |
|---|---:|---|
| 평행로·2차원 교차·겹침 | 11,080 | 보류 |
| 좌표는 일치하나 높이나 교차 층위 미확인 | 152 | 보류 |
| 기존 우회 대비 절감 0.5m 이하 | 7,532 | 축약 실험망에서 생략 |
| 분리된 연결망 연결 / 기존 우회 2km 이상 감소 | 337 | 원본·고도 근거 우선 대조 |
| 나머지 횡단형 미확인 후보 | 16,983 | 계획용 후보 유지 |

검사 결과는 **물리적 연결 확인이나 통행 허가가 아니다**. 모호한 2D 교차점은 실제로 다리나 터널, 절벽일 수도 있다. 자동 분류는 실험 경로의 오작동 가능성을 줄일 뿐이다.

## 비교

- 원본 분리 구성요소 3,571개
- 모든 35m 접합을 포함한 v129 실험망 3,282개
- 보류·실효 없는 연결선을 제외한 축약 실험망 3,410개
- 기존 2km 이상 우회를 줄이는 미확인 접합 246개. **이 중 97개가 기하학적으로 주의가 필요한 유형**이다.
- 앵커 간 좌표·연결선 거리 최대 불일치 0.141m.
- 원본 노드·간선·DEM 및 공개 사이트의 경로계산 코드는 수정하지 않았다.

산림청 GIS 원본은 주로 2016년 자료로, 현재 개방 여부·실제 통과 가능한 교차점·현장 지형을 확정할 수 없다. 따라서 사용자 요청으로 복원한 **한계령**은 위 35m 자동 분류와 별도 기준 사례로 보존한다. 기존 v69에 포함된 73.19m 계획용 연결선은 원본 SHP 최단 간격이 약 48.73m이므로 35m 일반 접합 규칙에 포함되지 않는다.

## 재현 가능성

현재 대화에서 생성한 `sanbakmap_v130_nationwide_connection_quality.zip`에는:
- 산별 32개 `bucket-XX.json.gz` 결과
- 전수 집계 `summary.json`
- 실제 원본 v129 ZIP에 대해 최단경로를 재계산하는 `audit_v130.py`
- 기존 원본 및 v129 대비 QA 무결성을 확인하는 `validate_v130.py`

를 포함했다. 이 저장소에는 대용량 32개 연결망 파일을 중복 커밋하지 않고 집계와 테스트만 유지한다.

**원본 데이터의 링크 승인 여부: 모두 `false`.**
