# 산박지도 v131 · 전국 연결망 고도 교차검증

이번 단계에서는 기존 v130 품질검사에서 **우선 검증 대상**으로 분류된 337개 접점을 전국 원본 간선 DEM과 대조했다. 화면·기능 변경은 없다.

## 방법

원본 SHP 출처 SHA-256을 고정하고, v129에서 복원한 원본 간선과 분할 간선의 길이 정보를 v109의 원본 간선별 압축 DEM 표본과 대응시켰다. DEM 표본 간격은 **90m이며 원본 래스터 해상도와 수직기준은 불명**이다. 각 접점 양끝 높이를 대응시키고, 하나의 노드에 서로 다른 원본 간선 높이값이 함께 있는 경우 내부 불일치가 5m를 넘으면 무효 처리하도록 했다.

모든 임시 연결은 2016년 중심 산림청 원본 자료를 사용하므로 현장 통행 상태가 검증되지 않은 상태다. 고도차가 작다고 연결을 공식 등산로로 승격하지 않는다.

## 결과

| 종류 | 건수 |
|---|---:|
| v130 우선 후보 | 337 |
| 양쪽 끝 고도 확인 가능 | 219 |
| 고도차 5m 이하 (통행 미확인) | 179 |
| 중간 고도차 / 경사 검토 필요 | 38 |
| 큰 고도 불일치 의심 | 2 |
| 한쪽 표본 없음 | 65 |
| 양쪽 표본 없음 | 53 |

고도차 15m 초과 **동시에** 수평거리 대비 표본 고도차 비율 0.6 초과인 경우만 큰 고도 불일치 의심으로 분류했다. 이 조건은 **절벽 또는 실제 통행불가 판정 기준이 아니라 데이터 이상 탐지용**이다.

두 의심 후보: `413602201` (임시 간선 135번, 19.05m 횡거리·DEM 고도차 25.59m), `414600103` (603번, 21.71m 횡거리·DEM 고도차 24.30m).

기존 축약 실험망에 17,320개 계획용 임시 접합이 있었다면 두 의심 후보를 **실험망에서만** 보류했을 때 17,318개가 남는다. 축약 실험망의 분리 구성요소는 3,410 → 3,411개로 변화한다. 원본 전체 36,084개 접합 후보, 원본 연결망, DEM, 공개 웹 라우팅은 모두 그대로 보존했다.

## 검증 한계

- v109 ZIP은 전국 2,723개 산의 DEM 표본을 담고 있지만, 이번 190개 산 중 DEM을 가진 산은 185개다.
- 산에 DEM이 있어도 접합의 양쪽에 표본이 모두 있는 것은 아니다. 이번에는 118개 접합의 양끝 높이 비교가 불가능했다.
- 한계령은 사용자가 실제 연결을 확인한 별도 사례로 보존한다. 원본 SHP에서 48.73m 떨어진 사례이므로 35m 일괄 규칙 및 이번 337개 안에는 없다.
- 특히 90m 표본으로 **35m 이하 접합 지형을 직접 측정한 것이 아니다.** 높이차의 인과 관계를 단정하지 않는다.

## 재현성

전체 32개 버킷별 후보 결과, 표본 근거, ZIP 입력 SHA-256, Python 표본 디코더·전체 재계산기·독립 검증기·축약망 비교 재계산 코드는 대화 내 ZIP 파일 `sanbakmap_v131_nationwide_dem_connection_audit.zip`에서 제공한다. 원본 ZIP을 중복해서 GitHub에 저장하지 않고 결과 집계와 테스트만 올렸다.
