# v137 — 평면 접촉 고도 미확인 7곳, 원본 정밀 원인 분석

v136에서 원본 3D 높이가 양끝 모두 확인되지 않은 평면 접촉 15개 기록을 **7개 고유 원본 노드쌍**으로 묶어 산림청 원본 SHP, v102 원본 토폴로지, v129 원본 보존 그래프, `output_elevation.zip`과 독립 대조했다. 그 외 137건의 v136 양끝 3D 고도 검사, 2,902곳 산·공원, 원본 DEM 및 공개 경로망은 변경하지 않았다.

## 확인 결과

- 5개 산코드에 분산된 7개 접점, 15개 원본 후보 기록.
- **6곳:** 9개의 서로 다른 미확인 원본 간선이 원본 SHP 내 **0~0.11m**의 아주 짧은 절단 조각. 기존 전체 선형 기하 정밀매칭 허용치(0.3m)보다 짧아 3D 자료 안에서 고유 선형을 확정할 수 없다.
- **1곳:** 산코드 `437201201`의 `original_shape_orphan` 원본 선형 4,394.270m / 410버텍스. 가까운 3D 선형은 원본 버텍스와 최대 0.0594m 근접하지만, 해당 구간의 길이는 **64.827m 차이**이고 대칭 Hausdorff 거리 **28.137m**로 전체 선형 정합에 실패한다. 겉보기 근접만으로 고도 또는 통행 가능한 간선을 만들 수 없다.
- 원본 토폴로지 상 서로 떨어진 연결요소를 잇는 후보(`437201201`)도 보류를 유지했다.
- **원본 고도 복원 0건, 실제 통행 연결 승인 0건.** 35m 규칙이나 한계령 사용자가 확인한 예외의 의미도 변경하지 않았다.

## 재현 자료

정확한 원본 SHA-256, 대상 7개 노드쌍, 링크 ID 및 원인 분류는 `audits/v137-missing-contact-root-causes.json`에 기록. 사용자 대화의 `sanbakmap_v137_7_missing_contacts_diagnostic.zip`(SHA-256 `7e8154b8176a7bff3d29e5abf4ec07ed3fda8f1249e738da6f1d16d93e19e479`)에는 원본 파일·행·파트, 원본 간선 ID와 누락 노드, 실제 기하오차가 포함된 `missing-site-root-causes.json`, 산출 스크립트 `audit_v137_missing_contacts.py`, v135/136과 같은 3D 원본 검증 보조 모듈, 독립 검증기 `validate_v137.py`를 넣었다.

**자동 분류만 수행:** 짧은 선형/고립된 원본 선형을 일괄적으로 이어 붙이지 않는다. 3D GIS의 높이는 원시 DEM 래스터의 수직정확도, 현장 통행 가능 여부, 법적 접근 가능 여부나 교차로·교량의 접속을 입증하지 않는다.
