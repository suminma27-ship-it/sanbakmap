# v141 전국 데이터 감사의 버전 간 회귀 검사

2026-11-09, v140까지 공개된 전국 감사 JSON 13개(v128–v140)를 다시 읽고 **26개 독립 교차 검증 조건**을 실행했다. 26개 모두 통과. 저장소 테스트 `tests/nationwide-audit-invariants-v141.mjs`에 동일한 조건을 영구화했다. GitHub Pages의 직전 v140 실행은 성공으로 확인했다.

이 검사는 원본 SHP, v102, v129의 **기록된 SHA-256 문자열이 여러 감사 사이에서 일관적인지**와, 후보·분류·DEM 회복·연결요소 등 **기록된 집계의 산술 일관성**을 확인한다. 원본 ZIP을 다시 내려받아 바이트 해시를 재계산하는 검사가 아니며 현장 통행을 증명하지 않는다.

검증 핵심:
- v128 144,990건의 원본 35m 접점 후보는 거리구간 및 관계 분류 양쪽에서 합계 일치.
- v129 후보 144,990 = 기존 동일 노드 108,906 + 임시 간선 36,084.
- v130 36,084개 후보의 형상 분류·품질 결정 두 합계 일치.
- v131·v135 고도 분류, v132–v134 고도 누락/회복, v136·v137 모호 접점, v138·v139 초미세 선형, v140 원본 양끝점 134,370개에 대한 집계 정합성 일치.
- SHP 원본, 원본 그래프, v129 계획용 그래프 SHA-256 기록의 버전 간 동일성 확인.
- 한계령 사용자 확인 예외는 35m 범위 바깥(원본 최소 48.7268m)으로 계속 별도 보존.

## 완료까지 남은 문제
1. v140 산코드 301101201의 1.16cm 원본 끝점 간격이 실제 분리인지 좌표 반올림 때문인지 원본 형상/출처로 확인.
2. v137의 3D 정보 미해결 고유 접점 7곳 및 v134의 491106604 고도 미해결 2곳은 증거 부족으로 유지.
3. 36,084개의 계획용 35m 간선은 현장·공식 출처로 통행이 확인되지 않았으며, 실제 연결로 자동 승격하지 않음.
4. 90m 간격 고도 샘플의 원래 DEM 해상도·수직기준, 전국 산 사이 연결성 및 v69 기준의 실제 경로 회귀 검증은 아직 미완료.

**변경:** 감사 문서·테스트만 추가. 원본 그래프/DEM/지도 기능 변경 없음, 해발 200m 이하 산·공원 제외 없음. 따라서 전국 데이터 정리 완료 선언 불가.
