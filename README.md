## v33 업데이트 (2026-11-06)
- 산행 **계획용 지도**에 맞게 선택 코스를 단일 녹색 선으로 복원.
- v32 색상별 GIS 근접도 경고/판정과 경로 검증 패널 제거.
- 공식 안내·조합 코스의 기존 출처 설명, 거리·고도 정보, 주요지점, 나만의 루트 만들기는 유지.
- 향후 개발 중점: 지도 위 지점 선택 → 연결 가능한 코스 조합 → 거리·고도그래프 자동 갱신.
- 계획용 안내는 간결하게 유지하며 실제 현장 통행/통제 가능 여부는 별도 확인 대상.

## v32 업데이트 (이전 버전, v33에서 지도 색상 구분 제거) (2026-11-06)
- 기존 GIS 연결망과 선택 코스의 선형을 25m 간격으로 샘플링해 근접도 분류.
- 지도에 녹색(GIS 근접), 황색(추가 확인), 적색(연결 근거 부족) 구간을 서로 다르게 그림.
- 코스 상세의 '경로 신뢰도 · 선형 점검'에서 각 분류의 거리 비중과 판단 기준 제공.
- 녹색은 **좌표 근접**만 의미. 연속된 실제 등산로·합법적 탐방·통제 해제의 증명이 아님.
- 구간별 GIS 대조 결과는 계획용 진단이며 원본 지리선형의 품질에 좌우됨.

- 기존 등산 코스와 코스 조합 및 루트 제작 기능 유지.
