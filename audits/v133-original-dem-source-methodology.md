# 산박지도 v133 — 원본 고도 자료의 정확한 부분 선형 복원

v132에서 고도가 없었던 118개 계획용 접합의 근본 원인은 원본 연결망의 관련 129개 간선에서 DEM 표본을 확보하지 못한 것이다.

사용자가 이전에 제공한 `output_elevation.zip`을 다시 찾았다. 이 자료는 기존 v109 DEM의 원본이며, 산별 GeoJSON에 3D 고도 좌표가 보존되어 있다.

## 복원 기준

예전 v109 방식은 **전체 원본 선형이 같아야** 고도를 연결했다. v133은 원본 SHP의 개별 간선이 고도 GeoJSON 선형의 **부분 구간**으로 포함되어도 인정하되 다음 모두를 확인한다.

- 동일 원본 산코드, 원본 간선 ID 및 두 끝점의 정밀 EPSG:5179 좌표 확인
- 시작·끝점 모두 고도 포함 선형에서 **0.25m 이내**
- 원본 간선 길이와 고도 선형의 대응 구간 길이 일치
- 원본 SHP에 기록된 중간 전체 좌표와 고도선형 대응 구간의 편차 **0.3m 이내** (실측 최대 **0.071m**)
- 대응 고도선형이 **유일**하며 유효한 3D 고도값이 존재
- 기존 v109 DEM 파일에 같은 간선의 표본이 있으면 **절대 덮어쓰지 않음**

## 전국 검사 결과

| 종류 | 수 |
| --- | ---: |
| v132 보강 대상 원본 간선 | 129 |
| 유일하고 정밀하게 일치한 간선 | **123** |
| 일치 근거가 부족해 남겨둔 간선 | **6** |
| 새로 생성한 90m 고도표본 | **1,568** |
| 118개 미확인 접합 중 고도 양쪽을 새로 확인한 접합 | **112** |
| 여전히 누락된 접합 | **6** |

새로 높이를 비교한 112개 접합 중 96개는 고도차 5m 이하, 15개는 고도차 5m 초과이되 큰 불연속 기준에 해당하지 않고, 1개는 `262900804` 산코드 접합 140 (수평 19.01m, 고도차 17.33m)으로 **데이터상 고도 불연속 의심**이다. 나머지 15개 중 1개는 고도차가 약 15.2m이지만 기울기 비율이 큰 불연속 기준에 못 미친다. 실제 안전성이나 등산로 연결 여부 판단은 아니다.

고도 포함 GeoJSON은 원본 DEM의 수직기준·실제 래스터 해상도를 증명하지 않는다. 90m 표본은 **이미 있던 3D 값만을 원본 선형에 투영하고 재표본화**한 것이다. 고도를 임의로 만들지 않았다. 35m 이내 선형 접합의 현장 통행·개방 여부도 미확인 상태다.

### 데이터·재현 코드

`sanbakmap_v133_verified_original_dem_recovery.zip`에 32개 압축 고도 샤드, 원본 간선 정체성, 미복구 6개 상세, 118개 접합 새 고도 대조, 4개 재현/검증 Python 스크립트와 ZIP 입력 해시를 포함했다. 원본 SHP와 전체 과거 ZIP을 GitHub에 중복 등록하지 않았다.

기존 산·공원 2,902곳 전체를 유지하며 원본 연결망, 원본 DEM, 지도 UI와 공개 경로계산은 변경하지 않았다.
