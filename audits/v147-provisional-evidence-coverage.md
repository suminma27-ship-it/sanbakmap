# v147 — 전국 35m 연결 후보의 증거 범위 감사

이번 단계는 GitHub에 보존된 **v128–v146의 출처·집계·고도 검증 기록을 교차 대조**하여, 전국 연결 후보 중 무엇이 실제로 검사됐고 무엇이 아직 검사되지 않았는지를 명시한다. 새 SHP·DEM 원본을 전수 재처리한 결과가 아니다.

전국 2,902곳의 35m 원본 근접쌍 **144,990쌍** 가운데 **108,906쌍**은 같은 노드로 집계되며, 계획용 연결 간선은 **36,084개**이다. v130은 이 36,084개 모두에 기하학적 유형과 계획용 판정 분류를 부여했다. 그러나 **현장 통행·공식 탐방로·고도차가 검증되었다는 뜻은 아니다.**

v130에서 **337개**를 우선 고도 재검토 대상으로 선정했다. v131은 이 337개에 대해 90m 간격의 보간 DEM을 검사했고, v135는 원본 연계 3D 높이로 **335개**를 대조했으며 **2개**는 높이 자료가 남아 있지 않다. 따라서 **전국 계획용 간선 대비 직접 3D 우선 검토 커버리지 = 337/36,084 = 0.93%**이다. 나머지 **35,747개**는 해당 *우선 검토 파이프라인*의 대상이 아니었다. 이것이 고도값 자체가 없거나 위험하다는 의미는 아니다. v131의 90m 보간 높이와 v135의 직접 3D 높이를 혼동하지 않는다.

v130 계획용 분류: 기하학적 보류 11,080개, 2D 레벨 미확인 152개, 우회 감소 미미 7,532개, 우선 재검토 337개, 미확인 계획용 유지 16,983개. 이 분류들은 정확히 36,084개를 분할한다. **보류·유지·생략은 원본 경로를 삭제하거나 새 실제 등산로를 승인하는 조치가 아니다.** v145의 57개 고위험 좌표 노드는 이 36,084개 간선과 다른 단위이므로 중복/합산하지 않는다.

v142의 과거 v69 규칙(0.75m 수평/4m 수직, 차수·연결요소·상호 유일성) 테스트는 규칙 수준이다. 전국 실제 그래프 후보의 v69 재생 및 결과 동등성은 아직 완료되지 않았다. 한계령은 사용자 확인 예외로 유지하며, 35m 자동 후보에 넣지 않는다.

완료 전 요구 사항: 36,084개 후보의 개별 원본/고도 증거 상태 표준화, v69 전국 그래프 회귀, 57개 좌표 우선 검토와 1개 분리 연결요소 근접쌍, 공식 탐방로 접근 여부, 원본 SHP·DEM 재현성/수직 기준 검증. 이 모든 항목이 완료되기 전에는 '전국 정리 완료'로 선언하지 않는다.
