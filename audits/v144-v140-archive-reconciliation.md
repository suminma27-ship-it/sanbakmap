# v144 — v140 전국 감사 ZIP의 독립 집계 재검증

v143 GitHub Actions 배포가 **성공**한 것을 확인한 후, 이전 v140 감사 산출물 ZIP을 실제로 다시 열어 **개별 2,902개 산·공원 CSV, 1,722개 양자화 합류 노드 JSON, 4개 2cm 이내 이격 노드 JSON**을 독립 집계했다. ZIP과 개별 파일 SHA-256은 JSON 기록에 보존했다.

## 독립 합계
- 산코드 2,902개, 중복 0. 원본 간선 합계 **67,185**, 노드 **59,301**, 산별 연결요소 **3,571**.
- 서로 다른 원본 좌표가 하나의 0.1m 그래프 노드에 들어간 항목 **1,722**; 그중 원본 좌표 최대 간격 5cm 초과 **114**. 전국 CSV 합계와 개별 JSON 레코드 집계가 일치했다.
- 서로 다른 양자화 노드 사이 원본 끝점 2cm 이내 **4쌍**. 그중 원본 연결요소가 서로 다른 것은 **1쌍**. 전국 CSV와 개별 JSON이 일치했다.
- 우선 점검: 산코드 **301101201**, 노드 81/80, 원본 끝점 거리 **0.011600m**. 좌표가 근접해도 공식 통행 가능성은 증명되지 않았으므로 연결 승인 **0건**.

## 제한
이 단계는 **v140 결과 파일의 독립 재집계 및 출처 해시 검증**이다. v102/v129 원본 그래프 전체와 DEM 원본을 재실행한 것은 아니며, 원본 SHP 좌표를 새로 수집하지도 않았다. 다음 단계에서 144,990개 35m 후보 중 0.75m 이내 사례의 원본 차수·연결요소·고도 및 역방향 유일성을 실제 그래프와 대조해야 한다.
