# v139 — 전국 초미세 선형 원본 연속성·경로망 보존 검증

## 검사 범위

전국 **2,902개 산·공원**에 대한 원본 v102 그래프 **67,185개 간선 / 59,301개 노드** 및 원본 v129 계획용 35m 그래프의 원본 접두부가 일치함을 확인했다. v138에서 전수검사한 15cm 이하 **521개 간선(257개 산·공원)** 을 원본 산림청 SHP(EPSG:5179)의 실제 버텍스와 재대조했다. 소스 ZIP과 그래프 ZIP의 SHA-256을 검증하고 원본 그래프·DEM·지도 UI를 전혀 변경하지 않았다.

## 결과

| 분류 | 개수 |
|---|---:|
| SHP 같은 원본 파트에서 인접 분할 간선이 확인된 미세 간선 | 477 |
| 인접 선형의 원본 공유 버텍스 동일 좌표 비교 | 486 |
| 양자화된 같은 그래프 노드에 시작·종료점을 둔 미세 간선 | 486 |
| 양자화된 서로 다른 노드를 연결한 미세 간선 | 35 |
| 서로 다른 노드 중 병합 가능한 차수 2 중간 노드가 없는 간선 | 14 |
| 서로 다른 노드 중 차수 2 중간 노드는 있으나 **동일 SHP 파트 연속 버텍스 범위가 아닌** 간선 | 21 |
| 35m 임시 접합과 끝점을 공유하는 서로 다른 노드의 미세 간선 | 26 |
| 차수 2 끝점이 있는 21개 중 해당 끝점에 임시 접합이 있는 간선 | 20 |
| **구조적으로 자동 병합 가능한 후보** | **0** |

**477개가 인접 원본 파트에 속한다는 사실만으로 자동 병합이 허용되는 것은 아니다.** 원본 노드의 분기 차수 2, SHP 파트·버텍스 구간 완전 연속, 계획용 35m 접합 미접촉, 루프 미변환, 원본 경유지·거리 보존 등을 동시에 증명해야 한다. 검증대상 35개는 해당 필요조건부터 만족하지 않았다.

원본 연결요소 수 **3,571**(산별 합계), v129 계획용 연결요소 수 **3,282**(산별 합계), 원본 간선 길이 총합 **33,511,880.18m**(v102의 1cm 기록 단위). 후자는 **계획용 후보 연결을 포함한 계산으로 실제 통행 가능성을 의미하지 않는다.**

v137에서 확인되지 않은 3D 원본 간선 **9개 및 고유 접점 7곳을 계속 보류**했다. 단순 삭제, 병합, 자동 연결 승인 모두 **0건**. 200m 이하 산·공원도 제거하지 않았다.

## 재현·독립 검증

별도 산출물 `sanbakmap_v139_nationwide_micro_chain_audit.zip`(SHA-256 `5b115f537926b4ffe6eff3ba42cc95cf25aae9c340c97d571414c88b700cda64`)에 521개 전수 행별 진단표 CSV/JSON, `audit_v139_continuity.py`, `validate_v139.py`, `v135_source_3d_helpers.py` 및 README를 저장했다. 독립 검증기는 원본과 계획용 전국 그래프를 다시 읽고 분류, 구성요소 수, 총길이 및 입력 SHA-256을 확인해 통과했다.

이 작업은 **원본 데이터 품질·정합성 검증**이며, 새 등산로·앱 기능·공식 탐방 허용·실제 통행 연결을 추가하거나 입증하지 않는다. 이후 데이터 개선은 원본 정밀좌표와 v102의 0.1m 노드 양자화 대응부터 다루는 것이 안전하다.
