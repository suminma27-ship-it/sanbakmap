# v132 · 전국 2,902개 산 보존 및 DEM 누락 원본 간선 자동 추적

**기존 산·공원 2,902곳은 제외하지 않고 모두 유지**한다. 200m 이하 산·공원도 삭제하거나 게시에서 숨기지 않는다.

v131의 우선 접합 337개 중 양쪽 고도 비교가 불가능한 **118개**에 대해 원본 산림청 연결망 간선 ID를 역추적했다. 구형 v109 DEM ZIP과 v129 정밀 연결망, v131 고도 평가 기록을 입력 SHA-256으로 대조했다.

| 결과 | 건수 |
| --- | ---: |
| 고도가 부족한 접합 | 118 |
| 해당 산에 DEM 자체가 없음 | 10 |
| 산의 DEM이 있지만 관련 원본 간선 표본 누락 | 108 |
| 영향을 받은 산 | 69 |
| 표본이 없는 접합 끝점(중복 포함) | 171 |
| 보강이 필요한 중복 제거 노드 | 150 |
| 최소 작업량을 지향한 원본 간선 표본 대상 | **129** |
| 분리된 원본 연결망 사이 접합 | 86 |
| 기존 원본 경로를 2km 이상 단축시키는 접합 | 32 |

대상 목록 `data/nationwide-elevation/v132-repair-edge-targets.json`은 정확한 **산코드 + v102 원본 간선 인덱스** 쌍을 129개 기록한다. 그래프를 재생성하면 간선 ID가 바뀔 수 있으므로 SHA-256으로 버전을 고정한다.

129개는 171개 미측정 끝점에서 중복을 제거하고, 이미 같은 원본 간선의 고도를 취득하면 여러 끝점이 함께 보강될 수 있다는 점을 이용한 탐욕적 집합 덮개(set cover) 결과다. **최소해를 증명하거나 고도가 이미 확보됐다는 뜻은 아니다.**

필요한 원본 표본을 실제로 구한 후에만 고도 평가를 재실행할 수 있다. 없는 고도를 지형 밖에서 상상하거나 임의 보간하지 않으며, 90m 표본으로 절벽·입체 교차·통행 가능 여부를 확정하지 않는다.

GitHub에는 자동 처리 규칙과 결과 집계를 보존하고, 접합 118개별 세부 원본 노드 및 후보 파일은 이 대화에서 생성한 `sanbakmap_v132_dem_missing_source_repair_plan.zip`에 포함했다. 배포 경로·지도·DEM·연결 그래프는 수정하지 않았다.

재현:
```bash
python tools/audit-dem-gap-v132.py --v129 sanbakmap_v129_original_35m_planning_graph.zip --v131 sanbakmap_v131_nationwide_dem_connection_audit.zip --v109-dem sanbakmap_v109_elevation_2723.zip --outdir ./dem-gap-v132
```
