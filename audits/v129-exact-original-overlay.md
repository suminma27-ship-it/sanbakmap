# v129: 전국 정밀 원본 연결망 계획용 자동 보정

새 기능 개발이 아니라, 사용자가 업로드한 `닭.zip` 원본 선형의 정확한 좌표와 SHA-256 검증된 v102 원본 연결망을 이용한 **데이터 파이프라인**이다.

1. 전국 2,902개 산, 원본 선형 66,503개를 정확히 대조했다.
2. v128 정확 좌표로 확인한 35m 이내 원본 선형 후보 `144,990`쌍을 원본 연결망의 관련 간선에 투영했다.
3. 이미 같은 노드를 공유하는 `108,906`쌍은 중복 연결하지 않았다.
4. 원본 간선 `20,838`개 분할 구간과 계획용 미확인 연결 `36,084`개, 원본 그래프가 생략한 초미소 부분 1개를 **별도 실험 연결망**에 추가했다.
5. 전국 기존 연결 요소 `3,571`개 → 실험망 `3,282`개. 166개 산에서 분리 요소 개수가 줄었다.
6. 원본 67,185개 연결 간선과 59,301개 원본 노드를 **삭제하거나 수정하지 않았다**. 새 연결에는 개방·통행 미확인 상태를 보존했다.
7. 생성된 전체 32개 데이터 버킷에 대해 노드 및 간선 참조 무결성, 원본 접두부 불변성, 연결 요소 수를 검증했다.

**중요:** 35m 내의 입체 교차·절벽·겹친 선형은 실제 통행 가능한 지름길로 확정할 수 없다. 그래서 공개 웹 지도의 라우팅에 이 실험망을 강제 적용하지 않았다. 실제 경로라고 주장할 근거는 원본 GIS 위치만으로 부족하다.

한계령은 사용자 확인 사례로 분리한다. v69 지정 점 간 73.19m, 산림청 원본 `51.zip` 피처 2075↔2086 사이 최단 48.73m. 35m 후보를 모두 합쳐도 한계령을 자동 복원했다는 뜻이 아니다.

관련 데이터 및 재구축 Python 코드는 이 대화의 `sanbakmap_v128_nationwide_original_35m_contacts.zip`과 `sanbakmap_v129_original_35m_planning_graph.zip`으로 제공했다.
