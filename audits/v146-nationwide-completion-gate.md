# v146 전국 데이터 정리 완료 판정 게이트

v145(커밋 1adedce2fb83a00467241dfaef7247d9c4937030)까지의 기존 감사 결과와 GitHub Actions 성공 여부를 확인했다. v145 CI는 성공했지만 이는 **전국 데이터의 실통행 검증 완료**를 뜻하지 않는다. 이번 단계에서는 전국 완료를 성급히 선언하지 않도록 기존 v140·v144·v145 감사 기록을 서로 대조하는 **기계 검증 가능한 완료 판정 게이트**를 추가했다.

- 대상 **2,902곳 / 원본 간선 67,185 / 원본 노드 59,301** (200m 이하 포함).
- v140 감사 ZIP SHA-256, 원본 source/topology/graph SHA-256을 참조하고 v144·v145의 해시 일치 및 1,722개 원본 좌표 충돌 의심 노드에서 추린 57개 우선 검토군의 수량을 재검증.
- 1mm→1cm→5cm→7.5cm→10cm로 필터가 엄격해질수록 노드/산/임시 간선 접촉 수가 증가하지 않는 **단조성 테스트** 추가.
- 원본 연결요소가 분리된 1.16cm 근접점 1쌍은 **미검증 상태**로 계속 유지.
- 전국 원본 SHP·DEM 재처리와 57개 노드별 차수·고도차·공식 탐방로 판정은 **아직 수행되지 않았다**. 감사 결과만으로 임시 35m 연결을 승인하지 않는다.
- 완료 판정은 **불가**. 미해결 게이트 6개는 JSON의 `incomplete` 필드에 명시한다.

이 단계는 **완료 기준 및 회귀 안전성 강화**이지 원본 산길 연결 오류를 수정한 단계가 아니다. 원본 데이터/DEM/공개 지도/한계령 예외/UI 변경 없음. 실제 연결 승인 0건.

다음 실행은 원본 SHP·v102/v129 그래프·DEM 실파일을 확보하여 우선 검토군 57노드의 연결 차수, 원본 간선·연결요소, 임시 접점 상대 노드, 고도차, 공식 탐방로 근거를 개별 추출해야 한다. 자료가 없다면 해시·검증 기록을 넘어서서 수치를 꾸며내지 말 것.
