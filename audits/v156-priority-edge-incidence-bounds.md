# v156 — 우선 양자화 노드의 35m 후보 간선 중복 계수 상·하한

기준 main: v155 `c2cce47f2c4c661b1fe54dc8601888e554e8c44f`. 입력 Git blob SHA: v140 `72f78e835c13cac887738a179000b2ef5899bbb3`, v145 `7d326a794710cc8f120dbe402a45180faf4e3a66`, v147 `925f5e94d334be2d375e0546162b52e2d188a1d8`.

v145의 5cm 초과 원본 좌표 벌어짐 114개 노드 중 57개(50개 산)는 임시 35m 간선과 접하며, 이 노드들에서 관찰된 **간선 끝점 접촉 횟수(incidences)는 150회**다. 하나의 무방향 간선은 양 끝점에서 최대 2회 집계되므로, 150회를 **서로 다른 150개 간선으로 해석하면 안 된다.** 후보 ID 목록이 없을 때 접촉한 고유 임시 간선 수는 최소 ceil(150/2)=**75개**, 최대 **150개**다. 이는 전체 임시 후보 36,084개의 약 0.208%~0.416%에 해당하며 **실제 승인 또는 검증 완료 비율이 아니다.** 57개 노드의 원본 SHP 검증이 끝났다는 의미도 아니다.

추가 자동 테스트: `node tests/nationwide-priority-incidence-bounds-v156.mjs`. 실행 시 감사 JSON 3개 입력 바이트의 SHA-256을 출력하고 전국 2,902곳/67,185간선/59,301노드, 57개 우선 노드/50개 산/150 접촉 횟수, 고유 간선 수 경계, 승인 0건을 검사한다. **입력 JSON 해시는 원본 SHP/DEM의 독립 해시가 아니다.**

기존 v155 GitHub Actions 실행 [42752308531](https://github.com/suminma27-ship-it/sanbakmap/actions/runs/42752308531)은 성공. 신규 v156 Actions 실행 결과는 별도 확인해야 하며, 실행 성공이 원본 실측 검증을 뜻하지 않는다.
