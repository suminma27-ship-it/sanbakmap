# v142 — v69 연결 규칙과 전국 35m 후보의 의미 분리

기준: v69 원본 커밋 `13920840c1e3566505f2521bf4f33822a1b8a069`, index.html blob `9b1851098d1135d4b856cd658db911a95f0abea8`. 이전에 보존한 원본 코드 인용 문서 `audits/v69-routing-v126-reference.md`를 기준으로 회귀 판정 함수를 독립 테스트로 작성했다.

v69의 일반 자동 스티치는 원본에서 서로 다른 연결요소인 **차수 1 끝점**에만 적용되며 수평거리 **0.75m 이하**, 수직차 **4m 이하**, 단일 후보 및 역방향 유일성, 대상이 차수 1이면 상호 유일성을 요구한다. v69 한계령 예외는 별도의 사용자 확인 계획용 브리지(약 73.19m)였으며 이 규칙과 무관하다. 기존 사용자 확인 사례를 제거하거나 공식 허가로 바꾸지 않았다.

v128의 원본 SHP 기반 35m 후보 144,990쌍 중 **109,392쌍**은 거리 밴드가 0.75m 이하, **35,598쌍**은 0.75m 초과다. 따라서 뒤의 35,598쌍은 v69의 일반 스티치 수평 임계치를 만족하지 않는다. 단, 이 숫자는 v129 임시 간선 36,084개와 **같은 집합이 아니다**. 각 쌍의 차수·연결요소·고도·역방향 유일성 여부를 보지 않고 실제 연결 승인 수를 추정해서는 안 된다.

`tests/nationwide-v69-stitch-rule-v142.mjs`는 v69 원본의 판정 조건을 재현한 순수 함수와 9개 반례/경계값을 검사한다. 0.75m·4m 경계, 초과, 같은 연결요소, 차수 1이 아닌 시작점, 복수 후보, 역방향 중복, 상호 유일성 조건을 확인한다. 이 테스트는 **규칙 단위 회귀**이지, v69 3D 국립공원 그래프와 v102 전국 산림청 그래프 사이의 동일 경로 재현이나 전국 실제 통행 검증은 아니다.

원본 SHP·v102/v129·DEM·UI·지도 경로망 모두 비변경. 추가 승인 0건. 다음에는 원본 개별 후보의 차수/컴포넌트/고도까지 검증할 수 있는 데이터가 확보된 경우에만 실제 후보별 호환성 평가를 실시한다.
