# v143 — v142 v69 회귀 테스트 실패 원인 및 수정

2026-11-09 기준 main 81d475f6의 GitHub Actions 42533624209는 'Validate route topology and UI regressions' 단계에서 실패해 사이트 배포가 건너뛰어졌다.

원인: v142 테스트의 'source degree one required' 사례가 실제 원본 v69 로직과 반대되는 기대값을 가졌다. 첫 번째 노드가 차수 2이고 두 번째 노드가 차수 1인 경우, 차수 1인 두 번째 노드가 **출발 후보**가 되어 차수 2인 첫 번째 노드로 연결을 만들 수 있다. v69 원본은 출발점만 차수 1을 요구하며, 대상 노드는 차수 2 이상도 가능하다. 따라서 기존 fixture가 예상한 빈 배열 대신 0:1이 정답이다.

테스트를 수정해 **차수 1 출발점 → 차수 2 대상 허용**을 명시적으로 확인하고, 양쪽 모두 차수 2인 경우 **연결 없음**을 별도로 검증한다. 9개에서 10개 사례로 늘어났으며, 프로덕션 라우팅 코드·원본 SHP·DEM·전국 그래프·지도 UI는 변경하지 않았다.

v142 메타데이터의 requiresDegreeOneSource=true는 그대로 맞다. 다만 '양 끝 모두 차수 1이어야 한다'는 해석은 잘못이다. 검증 기록의 이 오류를 회귀 테스트에서 수정했다.

전국 데이터 정리 완료 아님. 다음 단계는 v128 원본 144,990 후보 중 0.75m 이하의 원본 노드 차수, 연결요소, 3D 고도, 역방향 유일성에 대한 실제 그래프 대조이며, v129 임시 접합을 현장 검증 없이 확정해서는 안 된다.
