# 산박지도 (Sanbakmap)

산행 계획용 지도 프로토타입 v29. 국립공원 탐방로, 거리, 고도그래프, 경유지와 사용자 루트 만들기 기능을 포함합니다.

## GitHub Pages 게시
저장소 Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: main, /(root) → Save.

게시 주소: https://suminma27-ship-it.github.io/sanbakmap/

이 앱은 산행 계획용이며 현장 길찾기용이 아닙니다. 일부 코스는 개략적인 연결도와 추정 고도 정보입니다.
